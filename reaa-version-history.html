v0.1.0

Tri-Store Genesis

Foundation Pinecone Astra DB Supabase

Architectural inception establishing REAA's hybrid multi-store retrieval engine. Decoupled statutory legal research, direct project PDF document retrieval, and relational data querying across dedicated storage engines.

Technical Deliverables & Implementation Highlights:
  • Pinecone Vector Store: Configured 3,072-dimensional vector indexing across 4 discrete namespaces: rera-legal, rera-projects, rera-complaints, and rera-litigation using gemini-embedding-001.
  • DataStax Astra DB: Initialized unstructured collection rera_links for lightning-fast semantic retrieval of project document hyperlinks, sanction plans, and certificates.
  • Supabase PostgreSQL: Schema modeling for 9,800+ registered K-RERA projects, 52,500+ consumer/promoter complaints, and 16,500+ court litigations.
  • Intelligent Query Router: Built Gemini-powered router classifying user intent into statutory legal search, link lookups, or database aggregations.
v0.2.0

Statistical Intelligence & Agentic Text-to-SQL

Text-to-SQL PostgreSQL Agentic RAG

Integrated autonomous relational function calling. Equipped Gemini with an in-engine SQL execution tool to answer complex quantitative inquiries directly from verified database records.

Technical Deliverables & Implementation Highlights:
  • Text-to-SQL Tool Declaration: Created query_krera_sql_database function schema allowing Gemini to autonomously generate and execute read-only PostgreSQL queries.
  • Strict Query Bounding: Enforced guardrails preventing unsolicited promoter footprint crawling; bounded search strictly to user-specified entity or locality.
  • Structured Table Synthesizer: Formatted multi-project statistical aggregates (e.g., total project costs, district project counts) into clean Markdown tables.
  • Zero-Leakage Security: Implemented runtime sanitization to prevent raw SQL query dumps, database schema leakage, or internal thought exposure to non-technical users.
v0.3.0

Trilingual Statutory Lexicon

Vernacular Kannada Hindi RERA Act 2016

Engineered native multi-lingual statutory grounding. Enabled accurate, verbatim legal terminology translation across English, Kannada (ಕನ್ನಡ), and Hindi (हिन्दी) without semantic drift.

Technical Deliverables & Implementation Highlights:
  • Statutory Lexicon Engine: Developed getStatutoryLexiconDirective() providing precise vernacular definitions for RERA Section 18 delay interest and Section 4(2)(l)(D) escrow accounts.
  • Karnataka RERA Rule 18 Fidelity: Hardcoded statutory interest benchmark: SBI Highest MCLR + 2.00% in Kannada (ಎಸ್.ಬಿ.ಐ. ಗರಿಷ್ಠ ಎಂ.ಸಿ.ಎಲ್.ಆರ್ + 2.00%) and Hindi.
  • Form M vs. Form N Classification: Grounded distinction between Form M (Adjudication before Authority) and Form N (Compensation before Adjudicating Officer).
  • Fallback Statutory Generator: Formulated structured fallback legal advisory templates strictly referencing landmark Supreme Court and High Court precedents.

Session Persistence & Consultation Forking

State Engine Supabase RLS Sharing

v0.6.0

Liquid Token Streaming & Viewport Stabilizer

Streaming RAF Engine Auto-Scroll

Overhauled streaming text generation. Eliminated markdown flickering, visual jitter, and auto-scroll race conditions using an adaptive requestAnimationFrame throttling engine.

Technical Deliverables & Implementation Highlights:
  • Liquid RAF Ticker: Built use-liquid-stream.ts with a dynamic catch-up easing loop decoupling raw SSE network chunk arrival from UI rendering state.
  • Timestamp Render Throttling: Enforced a stable ~30ms rendering cadence, preventing react-markdown re-parsing stutter at monitor refresh rates.
  • Non-Colliding Viewport Tracking: Intelligent auto-scroll engine pausing programmatic scrolling during manual inspection and resuming smoothly on completion.
  • Strict Chronological Ordering: Resolved flex-direction regressions to guarantee user prompts remain permanently anchored above assistant responses.
v0.7.0

Multimodal Document Vision & Privacy TTL

Multimodal Gemini Vision pg_cron

Enabled native PDF document understanding directly within the chat interface. Integrated ephemeral cloud storage governed by strict automated deletion policies for zero data retention.

Technical Deliverables & Implementation Highlights:
  • Native Gemini Vision Pipeline: Converted uploaded PDF documents into raw Base64 inline data parts, allowing Gemini 3.5 Flash to inspect typed text, stamps, and floor plans without OCR.
  • Ephemeral Storage Bucket: Configured Supabase Storage bucket temp_documents for temporary file holding during active consultation sessions.
  • Automated 1-Hour TTL: Deployed a 15-minute pg_cron database routine automatically purging uploaded files older than 1 hour.
  • Server-Side Upload Fallback: Built /api/upload fallback route to ensure resilient uploads if direct client-side storage uploads encounter network issues.
